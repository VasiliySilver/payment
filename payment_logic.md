Бизнес-логика платформы

1. Автоворонка и покупка
Процесс:
	Пользователь попадает на автоворонку, созданную через ClickFunnels.
	В автоворонке предлагается выбрать план подписки (месяц или год) и совершить покупку через Stripe.
	После успешной оплаты в Stripe:
	Пользователь автоматически перенаправляется на вашу платформу на страницу с квизом (через webhook от Stripe или редирект с параметрами).
	Stripe передает данные о транзакции (например, customer_id, subscription_id, план и статус оплаты) на вашу платформу.
	Пользователь проходит квиз для персонализации опыта (определение интересов, уровня подготовки и целей).
	После завершения квиза:
	Пользователю предлагается зарегистрироваться (email + пароль, либо через OAuth, если это предусмотрено).
	На основе данных из Stripe подписка уже активна, и пользователю не нужно повторно вводить данные карты.
	
Техническая реализация:
	Webhook от Stripe синхронизирует данные о подписке с вашей базой данных.
	Пользователь получает уникальный идентификатор (user_id), который связывается с subscription_id из Stripe.
	После регистрации пользователь сразу попадает в личный кабинет с активной подпиской.

2. Как пользователь видит уже купленные курсы
Логика:
	После входа в личный кабинет пользователь попадает в раздел "My Plan".
	В этом разделе отображается:
	Список курсов, которые были куплены или добавлены в план на основе результатов квиза.
	Прогресс по каждому курсу (шкала прогресса: количество выполненных дней/тренировок).
	Календарь с расписанием тренировок или уроков.
	В разделе "Courses" пользователь может:
	Просмотреть доступные курсы (включая те, что уже куплены).
	Добавить новые курсы в свой план, если они входят в текущую подписку.
	Каждый курс имеет свою страницу с описанием, списком уроков и тренировками.
	Реализация:
	Купленные курсы привязаны к подписке пользователя в базе данных (например, таблица user_courses с полями user_id, course_id, progress).
	Система проверяет уровень подписки (месяц/год) и предоставляет доступ к соответствующим курсам.
	Пользователь видит только те курсы, которые уже оплачены или доступны в рамках его плана.

3. Как пользователю заапгрейдить план без подтверждения карты
Логика:
	В разделе "Upgrade my Plan" пользователь видит текущий план (например, "Month") и предложение перейти на другой (например, "Year").
	Если карта уже привязана через Stripe:
	Пользователь выбирает новый план.
	Система отправляет запрос в Stripe на обновление подписки (subscription.update), используя существующий customer_id и payment_method_id.
	Stripe автоматически списывает разницу в стоимости (если есть) с привязанной карты.
	После успешного обновления пользователь получает уведомление, и новый план активируется в кабинете.
	Подтверждение карты не требуется, так как данные уже хранятся в Stripe.
Реализация:
	В базе данных обновляется поле plan_type (например, с "month" на "year") и subscription_id (если он изменился).
	Пользователю показывается обновленный доступ к курсам или функциям, если они зависят от плана.

4. Как отредактировать токен Stripe (в админке)
Логика:
	В разделе админки "Payments" администратор может:
	Перейти в подраздел "Редактирование токена Stripe".
	Ввести новый API-ключ (например, sk_live_xxx) или публичный ключ (pk_live_xxx).
	Сохранить изменения, после чего система проверяет валидность токена через тестовый запрос к Stripe API.
	Это действие доступно только администратору с соответствующими правами.
	Реализация:
	Токен хранится в зашифрованном виде в базе данных (например, в таблице settings).
	При сохранении нового токена система обновляет конфигурацию для всех запросов к Stripe.
	В логах админки фиксируется, кто и когда изменил токен.

5. Как пользователю отменить подписку
Логика:
	В разделе "Профиль" -> "Subscription Payments" пользователь видит:
	Текущий план (месяц/год).
	Дату следующего списания.
	Кнопку "Cancel Subscription".
	При нажатии на "Cancel Subscription":
	Система отправляет запрос в Stripe на отмену подписки (subscription.cancel).
	Stripe подтверждает отмену, и подписка становится неактивной после окончания текущего оплаченного периода.
	Пользователь получает уведомление об успешной отмене.
	До окончания периода пользователь сохраняет доступ к платформе.
Реализация:
	В базе данных статус подписки обновляется (например, status: "canceled").
	Пользователь больше не видит активных курсов после истечения срока подписки.

6. Как посмотреть список подписок
Для пользователя:
	В разделе "Профиль" -> "Subscription Payments" отображается:
	Текущий план (Month/Year).
	Статус подписки (активна/отменена).
	История платежей (дата, сумма, статус).
	Данные подтягиваются из Stripe через API (subscription.list или charge.list).
	Для администратора:
	В разделе админки "Дашборд":
	Общее количество пользователей.
	Активные подписки (с фильтром по планам: месяц/год).
	Триал-подписки (если предусмотрены).
	В разделе "Payments":
	Список недавних транзакций из Stripe (дата, пользователь, сумма, статус).
	Администратор может фильтровать подписки по статусу, дате или пользователю.
	Итоговый процесс для пользователя
	Покупка через автоворонку:
	Пользователь оплачивает подписку через ClickFunnels + Stripe.
	Перенаправляется на квиз.
	Регистрация и доступ:
	После квиза регистрируется и сразу видит активную подписку в кабинете.
	В "My Plan" отображаются купленные курсы и прогресс.
	Управление подпиской:
	В "Upgrade my Plan" апгрейдит план без ввода карты.
	В "Subscription Payments" отменяет подписку или смотрит историю.
Админка:
	Администратор управляет токеном Stripe, видит подписки и транзакции.
