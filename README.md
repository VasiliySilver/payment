# Многошаговая воронка оплаты с исправленной логикой для триала реализована:

Бэкенд (FastAPI)

Фронтенд (React/Vite): Отображает отдельные страницы для каждого шага воронки с кнопками покупки/пропуска.

## Инструкции по запуску и тестированию
1. Перезапустите бэкенд (если не перезапустился автоматически):
```bash
cd tests/payment/backend && uvicorn main:app --reload --port 8000
```

2. Перезапустите фронтенд (если не перезапустился автоматически):
```bash
cd tests/payment/frontend && npm run dev
```

3. Убедитесь, что Stripe CLI запущен (в третьем терминале):
```python
stripe listen --forward-to localhost:8000/webhook
```

4. Тестируйте: Откройте фронтенд в браузере (обычно http://localhost:5173). Пройдите по шагам воронки, начиная с "Start Trial ($1)". Ошибка должна быть исправлена. Протестируйте весь флоу, включая пропуски шагов. Следите за логами бэкенда и Stripe CLI.
